 Pizza Sales Analysis – Power BI Dashboard

 Project Overview

This project focuses on analyzing pizza sales data to understand business performance, sales trends, and revenue insights using Microsoft Power BI.

The dashboard provides meaningful visualizations to monitor key sales metrics, identify top-performing pizza products, and evaluate sales performance.

 Project Objectives

- Analyze overall pizza sales performance.
- Track total revenue and sales trends.
- Identify best-selling and least-selling pizzas.
- Analyze sales by pizza category and size.
- Compare actual sales performance with sales targets.
- Generate actionable business insights through interactive dashboards.

 Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- Data Cleaning and Data Analysis
- Data Visualization
- DAX (Data Analysis Expressions)

 Key Features

- Interactive Sales Dashboard
- Revenue and Sales Analysis
- Pizza Category and Size Analysis
- Best-Selling Pizza Identification
- Sales Target Comparison
- Business Performance Insights

 Project Files

This repository contains the Power BI dashboard file and supporting Excel datasets used for the analysis.
